# diagrams ディレクトリの運用指示

このディレクトリには、通信要件を視覚化した draw.io 図と、その SVG 出力を配置する。

## 正本と生成物

- 通信要件の正本は `../../requirements/communication.yaml` である。リソース、通信経路、ポート、プロトコル、説明は必ず YAML と一致させる。
- `communication.drawio` は、YAML の内容を基に AI が編集・生成してよい。視認性を上げるための配置・余白・経路の調整は AI の裁量で行う。
- `communication.svg` は `communication.drawio` からエクスポートする。SVG を直接編集しない。
- YAML にないリソースや通信を、図の見栄えだけを理由に追加しない。補助要素（枠・注釈・凡例）は追加してよい。
- YAML を変更した場合は、CSV と図の両方を更新し、通信要件との整合性を確認する。

## draw.io の編集方針

- `communication.drawio` は draw.io / diagrams.net で開ける XML 形式を維持する。圧縮形式へ変換しない。
- AWS リソースには AWS4 ライブラリのアイコンを使用する。独自の絵文字、汎用クリップアート、別ベンダーのアイコンは使わない。
- ラベル、ポート・プロトコル、CIDR、リージョン名、AZ 名は読みやすい日本語または既存表記に統一する。リソース名のラベルはアイコンの右側に置く。
- 接続線はリソースやラベルと重ならないように、必要に応じて直角の経由点を置く。通信の方向が分かる終端矢印を付ける。
- 通信ラベルは `TCP 443` のようにプロトコルとポートを表示し、白い背景を付けて線と重ならないようにする。
- Primary/Standby の同期レプリケーションなど、通信要件とは別の関係は、破線かつ専用色で明示的に区別する。

## 現在のビジュアル規約

| 項目 | 指定 |
| --- | --- |
| 背景 | 白（`#FFFFFF`） |
| グリッド | 10 px |
| 基本フォントサイズ | 12 px |
| 基本文字色 | `#232F3E` |
| アイコン寸法 | 60 × 60 px、縦横比を固定 |
| アイコンラベル | 右配置、左揃え、アイコンとの間隔 8 px |

| 対象 | AWS4 アイコン | 色 |
| --- | --- | --- |
| Application Load Balancer | `elastic_load_balancing` | `#8C4FFF` |
| ECS | `ecs` | `#ED7100` |
| RDS | `rds` | `#C925D1` |
| NAT Gateway | `nat_gateway` | `#8C4FFF` |
| Internet Gateway | `internet_gateway` | `#8C4FFF` |

通常通信は濃紺 `#232F3E` の実線・終端は塗りつぶしブロック矢印とする。レプリケーションはマゼンタ `#C925D1` の破線・矢印なしとする。

## 出力前の確認

- すべての YAML リソースが図中に存在すること。
- すべての YAML 通信について、送信元・宛先・方向・プロトコル・ポートが図と一致すること。
- アイコン、ラベル、矢印、通信ラベルが重なっていないこと。
- `communication.drawio` を開き直せること、および `communication.svg` が最新の図を反映していること。
